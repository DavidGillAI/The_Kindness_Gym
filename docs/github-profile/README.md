## How I work

I use AI-assisted coding to build and investigate prototypes. My portfolio focuses on the requirements, workflow decisions, integration, testing and communication around those systems. It does not claim that I wrote every line independently or that a successful demo establishes production readiness.

I document failures and uncertainty alongside results. For example, my [claim-classification evaluation](https://github.com/DavidGillAI/DRAGNET_LangSmith_Claim_Evaluation/blob/main/evaluation_summary.md) records improvement on a small development dataset and explains why unseen testing is still needed.
